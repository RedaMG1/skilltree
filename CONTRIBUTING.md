# Contribuer à Skilltree

Merci de vouloir améliorer **Skilltree**, une roadmap DevOps interactive en français.

## Avant de commencer

- Consulte les [issues](https://github.com/RedaMG1/skilltree/issues) pour vérifier qu'une amélioration n'est pas déjà proposée.
- Pour une évolution importante, ouvre une issue décrivant le besoin avant de coder.
- Ne publie pas de secrets, jetons, données personnelles ou informations professionnelles internes.
- Respecte les licences et l'attribution des ressources tierces.

## Développement local

Aucune installation ni compilation n'est nécessaire.

1. Fais un fork du dépôt et clone ton fork.
2. Ouvre `index.html` dans ton navigateur.
3. Modifie uniquement les fichiers nécessaires.
4. Vérifie les deux vues (« Mes skills » et « Roadmap DevOps complète »), les badges et les interactions sur ordinateur et mobile.
5. Vérifie les clics simples, Maj+clic, Alt+clic, la sauvegarde locale et la réinitialisation.

## Pull requests

- Crée une branche dédiée par changement.
- Utilise un titre clair (ex. `fix: corriger l'affichage sur mobile`).
- Décris le problème, la solution et les étapes de vérification.
- Ajoute une capture d'écran avant/après si tu modifies l'interface.
- Garde les PR petites et ciblées pour faciliter leur revue.

Les corrections utiles, l'accessibilité, les traductions et les améliorations de documentation sont bienvenues. Les changements artificiels destinés uniquement à augmenter un compteur de contributions ne sont pas souhaités.

## Contenus tiers

La liste des sujets DevOps s'inspire notamment de [roadmap.sh/devops](https://roadmap.sh/devops). Une contribution ne doit pas copier du contenu tiers sans vérifier les conditions de réutilisation.
