# Skilltree — Roadmap DevOps interactive

Une roadmap DevOps interactive en français pour visualiser les compétences à acquérir et suivre sa progression, sans installation.

## Utiliser l'application

1. Télécharge le dépôt ou clone-le avec `git clone https://github.com/RedaMG1/skilltree.git`.
2. Ouvre `index.html` dans un navigateur récent.
3. Choisis **Mes skills** pour la sélection personnalisée ou **Roadmap DevOps complète** pour la vue étendue.
4. Clique sur une compétence pour la marquer comme acquise :
   - **Clic** : fait
   - **Maj + clic** : en cours
   - **Alt + clic** : à passer
5. Clique de nouveau dans le même mode pour effacer son statut. Le bouton **Réinitialiser** efface les statuts de progression.

La progression est enregistrée localement dans le navigateur avec `localStorage` : aucun compte et aucun serveur ne sont nécessaires. Les données sont propres au navigateur et à l'appareil utilisés.

## Développement

Le projet utilise HTML, CSS et JavaScript sans processus de compilation. Ouvre directement `index.html` pour tester tes modifications.
