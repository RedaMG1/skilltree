# skilltree

Roadmap DevOps interactive (style roadmap.sh) pour suivre mes compétences.

- **Mes skills** : les compétences demandées pour le poste + mes pistes à explorer.
- **Roadmap DevOps complète** : tous les sujets de https://roadmap.sh/devops.

Ouvre `index.html` dans le navigateur.
Clic = fait · Maj+clic = en cours · Alt+clic = passer.
La progression est sauvegardée dans le navigateur.
